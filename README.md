# 원터치 배포

내 웹페이지를 **인터넷 주소로 열리게** 합니다.

## 쓰는 법

이 주소를 복사해서 **클로드(Claude Code)에 붙여넣고 "이거 해줘"** 라고 하세요.

```
https://github.com/soduthen-coder/github-vercel-onetouch
```

끝입니다. 터미널도, 명령어도, 깃허브 사용법도 몰라도 됩니다.
클로드가 필요한 것을 설치하고, 저장소를 만들고, 배포하고, 주소를 알려 줍니다.

사람이 할 일은 **브라우저에서 로그인 승인 두 번**뿐입니다.

## 미리 만들어 둘 것

| | 어디서 |
|---|---|
| 깃허브 계정 | [github.com/signup](https://github.com/signup) |
| 버셀 계정 | [vercel.com/signup](https://vercel.com/signup) — **Continue with GitHub** 을 고르세요 |

둘 다 무료입니다. 2단계 인증은 설정하지 않아도 됩니다.
