인터넷에 올리는 법을 모르겠다면

깃허브에 올리고, 버셀로 주소를 만들고, 잘 열리는지 확인하는 것까지 명령 한 줄이면 끝납니다. 가입만 되어 있으면 20초 걸립니다.

$ bash start.sh

이 한 줄을 터미널이라는 앱에 붙여넣고 엔터를 누르면 됩니다. 터미널이 뭔지 모르셔도 괜찮습니다. 아래에서 여는 법부터 알려드립니다.

터미널이 뭔가요

글자로 컴퓨터에게 시키는 앱입니다. 이미 컴퓨터에 들어 있습니다. 무섭게 생겼지만 우리가 할 일은 한 줄 붙여넣고 엔터, 그게 전부입니다.

MINGW64 ~
$

이렇게 생긴 창입니다. 여기에 붙여넣습니다.

윈도우

  1. 키보드 윈도우 키 를 누릅니다
  2. git bash 라고 입력합니다
  3. 나오는 Git Bash 를 클릭합니다

git 을 설치하면 함께 깔립니다. 안 보이면 아직 설치 전입니다.

맥

  1. ⌘ + 스페이스 를 누릅니다
  2. 터미널 이라고 입력합니다
  3. 엔터를 누릅니다

처음부터 들어 있습니다. 따로 설치할 것이 없습니다.

붙여넣기가 안 되면

윈도우 Git Bash 에서는 Ctrl+V 가 안 먹습니다. 창 안에서 마우스 오른쪽 버튼을 누르면 붙여넣어집니다. 맥은 ⌘+V 로 됩니다.

무엇이 달라지나요

지금 컴퓨터 안에만 있는 파일이, 누구나 열 수 있는 주소가 됩니다.

내 컴퓨터의 index.html
깃허브 저장소에 업로드
버셀이 인터넷에 공개
https://내사이트.vercel.app

먼저 갖춰야 할 네 가지

모두 무료입니다. 이미 있는 것은 건너뛰세요. 도구가 알아서 확인합니다.

  • 깃허브 계정파일을 보관하는 곳 · 가입하기
  • 버셀 계정인터넷 주소를 만들어 주는 곳 · 가입하기 (Continue with GitHub 을 고르면 빠릅니다)
  • git파일을 올려 주는 프로그램 · 받기
  • Node.js배포 도구를 설치하는 데 필요 · 받기

시작하기

위에서 연 터미널 창에 아래 줄들을 차례로 붙여넣습니다. 한 줄씩 엔터를 누르세요.

  1. 도구 내려받기

    깃허브에서 이 도구를 통째로 가져옵니다.

    git clone https://github.com/soduthen-coder/github-vercel-onetouch.git
cd github-vercel-onetouch

  2. 실행하기

    모자란 도구를 설치하고, 로그인을 안내하고, 첫 사이트를 만들어 배포합니다. 브라우저에서 로그인 승인만 해 주시면 됩니다.

    bash start.sh

  3. 주소 받기

    끝나면 주소가 나옵니다. 실제로 열리는지까지 확인한 결과를 함께 보여 줍니다.

윈도우에서 터미널이 어렵다면 start.cmd 를 더블클릭해도 됩니다.

클로드에게 시킬 수도 있습니다

Claude Code 를 쓰신다면 명령어를 외울 필요가 없습니다. 저장소 주소를 붙여넣고 말로 시키면 됩니다.

새 사이트 만들어 줘저장소를 만들고 배포까지 합니다
고친 거 올려 줘수정한 내용을 반영합니다
잠가 줘 / 공개해 줘나만 보기와 전체 공개를 오갑니다
내려 줘저장소와 사이트를 지웁니다

한글 이름을 말해도 됩니다. 포트폴리오 라고 하면 저장소 이름은 poteupolrio 로 알아서 바꾸고, 화면에 보이는 제목은 한글 그대로 둡니다.

직접 쓸 때의 명령

첫 배포를 마친 뒤부터 쓰는 것들입니다.

bash new-site.sh 이름사이트를 하나 더 만듭니다
bash publish.sh "메모"고친 내용을 올립니다
bash protect.sh 이름 on나만 볼 수 있게 잠급니다
bash protect.sh 이름 off다시 공개합니다
bash remove-site.sh 이름저장소와 사이트를 지웁니다

딱 하나만 기억하세요

저장소를 비공개로 뒀다고 사이트까지 가려지는 것은 아닙니다. 코드와 웹페이지는 따로 놉니다. 배포된 주소는 아는 사람이면 누구나 열 수 있습니다.

남에게 보여 줄 것이 아니라면 bash protect.sh 이름 on 으로 잠그세요. 반대로 과제처럼 남이 열어야 하는 것은 잠그면 안 됩니다.
