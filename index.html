딱 하나만 기억하세요

저장소를 비공개로 뒀다고 사이트까지 가려지는 것은 아닙니다. 코드와 웹페이지는 따로 놉니다. 배포된 주소는 아는 사람이면 누구나 열 수 있습니다.

남에게 보여 줄 것이 아니라면 클로드에게 “잠가 줘” 라고 하세요. 반대로 과제처럼 남이 열어야 하는 것은 잠그면 안 됩니다.

클로드 없이 직접 하려면

터미널을 쓸 줄 안다면 이렇게도 됩니다. 대부분은 열어 볼 일이 없습니다.

터미널로 직접 실행하기

1. 터미널 열기

터미널은 글자로 컴퓨터에게 시키는 앱입니다. 이미 컴퓨터에 들어 있습니다.

  1. 윈도우 — 윈도우 키 를 누르고 git bash 를 입력해 실행
  2. 맥 — ⌘+스페이스 를 누르고 터미널 을 입력해 실행

2. 붙여넣기

윈도우 Git Bash 에서는 Ctrl+V 가 듣지 않습니다. 창 안에서 마우스 오른쪽 버튼을 누르면 붙여넣어집니다. 맥은 ⌘+V 로 됩니다.

3. 한 줄씩 실행

git clone https://github.com/soduthen-coder/github-vercel-onetouch.git
cd github-vercel-onetouch
bash start.sh

윈도우라면 내려받은 폴더의 start.cmd 를 더블클릭해도 됩니다.

미리 설치해야 하는 것

git 과 Node.js 가 필요합니다. 기본 설정 그대로 설치하고 터미널을 껐다 켜세요. 클로드에게 맡기면 이것도 대신 설치해 줍니다.

그 다음 명령

bash new-site.sh 이름        사이트 하나 더 만들기
bash publish.sh "메모"       고친 내용 올리기
bash protect.sh 이름 on      나만 보기
bash protect.sh 이름 off     다시 공개
bash remove-site.sh 이름     지우기
